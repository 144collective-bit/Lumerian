## How to read evidence

| Layer | What it means |
|---|---|
| Page-image check | A listed Gaskell opening or printed scripture locator was read on the 1960 scan PDF. Only the pages in the check note, not the whole dictionary. |
| Installed source text | The KJV (Project Gutenberg #10, born-digital), Hall chapter text, Bullinger, The Witness of the Stars, and Blavatsky, *Isis Unveiled* (front matter read; numbered chapters extracted, not yet read), already in `Books/` |
| Unreviewed OCR | Almost all Gaskell entries remain `machine-extracted-unreviewed` |
| Explicit citation | Parser-validated `Bridges/` notes, or locators now marked `image_validated_print_locator` |
| Citation overlay | Damaged OCR locator recorded separately; original string kept |
| Keyword suggestion | Shared vocabulary only — not corroboration |
| Editorial comparison | A researcher juxtaposition (for example Hall beside Gaskell). Not mutual citation |

Wikilinks into the KJV tree use the plain folder name `King James Bible (Project Gutenberg 10)`. Verse links should use `#^kjv-…` block IDs.
