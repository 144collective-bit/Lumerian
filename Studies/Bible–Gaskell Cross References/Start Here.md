# Bible–Gaskell Cross References — Start Here

Additive research layer over the **entire** current Gaskell dictionary import and the installed **KJV (Project Gutenberg #10)**. Existing Gaskell and Bible notes are **unchanged**; this folder only adds bridges and indexes.

## What this is / is not

| Is | Is not |
|---|---|
| Explicit citation locators → KJV verse/chapter IDs | Claim that Gaskell quotes the KJV wording |
| Separate keyword/symbol lexical suggestions | Semantic/symbolic equivalence graph |
| Two-way browsing via bridges + Obsidian backlinks | Edits to source OCR or scripture files |

## Concrete usage

1. **From a Bible book:** open [[Studies/Bible–Gaskell Cross References/By Bible Book/01 Genesis|Genesis index]] (all 66 books listed below). If status is `no_confirmed_connections`, there is no parser-validated bridge yet — not a claim of absence in Gaskell’s thought.
2. **From a Gaskell entry that cites Scripture:** open the entry, then use backlinks to bridge notes, or browse [[Studies/Bible–Gaskell Cross References/By Gaskell Entry/Reverse Index|Reverse Index]].
3. **Example bridge:** after install, search vault for `Abel` bridges or open Bridges notes linking Genesis 4:8.
4. **Citation corrections (OCR-damaged locators):** [[Studies/Bible–Gaskell Cross References/Citation Corrections/Start Here|Citation Corrections]] — original OCR + proposed KJV target; **not** parser-validated Bridges.
5. **Keyword explore (not citations):** [[Studies/Bible–Gaskell Cross References/Keyword Suggestions/Start Here|Keyword suggestions]] — e.g. headword *altar* → KJV verses containing *altar*.
6. **Native search:** see Keyword Method for `path:"Books/King James Bible"` queries.
