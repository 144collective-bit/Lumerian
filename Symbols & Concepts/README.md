# Symbols & Concepts

Shared research hubs for symbols that already have evidence in more than one installed source. This folder is **not** a complete lexicon and not a claim that the authors agree.

Each hub keeps Gaskell OCR, installed KJV wording, Hall PDF locators, Bullinger and Blavatsky locators where a hub has been updated, and the Bible–Gaskell study layer in separate sections. Cross-source remarks are labelled `editorial comparison`, `explicit citation`, `citation_correction_overlay`, or `keyword suggestion`.

Gaskell entries used here remain `machine-extracted-unreviewed` unless a note says otherwise.

## How to use

1. Start at a hub, not at a keyword search alone.
2. Follow source links to the passage or OCR page.
3. Treat study-layer bridges as locator tools: a citation is not symbolic agreement.
4. Return unanswered questions to [[Studies/Linking Pass - 2026-11-06|Linking pass 1]], [[Studies/Linking Pass 2 - 2026-11-06|Linking pass 2]], or [[Studies/Linking Pass 3 - 2026-11-06|Linking pass 3]].
5. For Gaskell openings and recovered print locators checked against the scan, see [[Studies/Gaskell Page-Image Checks - 2026-11-06|page-image checks]]. Those checks do not make the rest of an entry, or the rest of the dictionary, reviewed.

## How to read evidence

Keep source-specific sections separate on every hub. Treat keyword hits as leads only. Treat Hall beside Gaskell as editorial comparison unless a citation is labelled otherwise.
