# Gaskell Dictionary Hub

**Prominent reference hub** for using Gaskell across the Lumerian vault.

## How to use Gaskell with every future book

1. When a symbol, deity-name, rite, or claim appears in another book, check whether Gaskell has an entry (once more of the dictionary is ingested).
2. If Gaskell speaks to it, add a **Gaskell** attributed section on the shared symbol/concept note — quoted and paraphrased separately from the other author.
3. Record **agreement, divergence, or absence** explicitly.
4. Do **not** treat Gaskell as automatic universal truth.
5. Do **not** infer historical influence between Gaskell and another author unless a source actually says so.
6. Other authors keep their own meaning first; Gaskell is a comparison lens.
